Responsive Design

Responsive design allows a website to adapt its layout, images and typography according to the available screen size. CSS Grid, Flexbox and media queries are commonly used.

Cheat Sheet

  • Use Flexbox for alignment.
  • Use Grid for page layouts.
  • Use media queries for breakpoints.
  • Use clamp() for flexible typography.
